# SkyMap

An interactive sky map that shows the sky at any date and time from 1500 to 2500 AD and any location on Earth, with [bright stars](http://tdc-www.harvard.edu/catalogs/bsc5.html) to magnitude ~6.5 on mobile, [more stars](https://southernstars.com/skymap.html) to magnitude 9 on desktop, the [Messier](https://en.wikipedia.org/wiki/Messier_object) and [Caldwell](https://en.wikipedia.org/wiki/Caldwell_catalogue) deep sky objects, and [planet positions](https://stjarnhimlen.se/comp/ppcomp.html) to arcminute accuracy near the present day. Computation includes corrections for precession, nutation, and atmospheric refraction.

SkyMap runs in any browser. It renders stars, constellations (stick figures, boundaries, labels), deep sky objects, planets, the Milky Way, coordinate grids and reference lines in both dark and light themes. It uses a stereographic projection with four different reference frames (Horizon, Equatorial, Ecliptic, Galactic). The view is zoomable and draggable; objects can be selected by clicking.

All code was generated by [Claude Code](https://claude.com/product/claude-code), prompted and tweaked by me (Tim DeBenedictis, timd@southernstars.com).

## Getting Started

Open [skymap.html](https://www.southernstars.com/skymap.html) in a browser. No build step or server required.

Getting your location from Wi-Fi will fail when opening the HTML file from local storage; to fix that, start a local server:

```
python3 -m http.server 8080
```

Then browse to http://localhost:8080/skymap.html

## Data generation

The JavaScript data files (`stars.js`, `constellations.js`, `deepsky.js`, `cities.js`, `milkyway.js`) are pre-generated and checked in. The Python scripts in `data/` regenerate them from source catalogs:

```
cd data
python3 gen_stars.py brightest.csv 6.0    # -> stars.js
python3 gen_stars.py SKY2000.csv 8.0      # -> stars.js (extended catalog)
python3 gen_constellations.py             # -> constellations.js
python3 gen_deepsky.py                    # -> deepsky.js
python3 gen_cities.py                     # -> cities.js
python3 gen_milkyway.py                   # -> milkyway.js
```

Most scripts auto-download their source CSV files from [SSCore](https://github.com/timmyd7777/SSCore) if not already present. Move the generated `.js` files into the project root to update the app.
