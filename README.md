# SkyMap

SkyMap is an interactive sky map that runs in any browser. It shows the sky at any date and time from 1500 to 2500 AD and any location on Earth. with [bright stars](http://tdc-www.harvard.edu/catalogs/bsc5.html) to magnitude ~6.5 on mobile, [more stars](https://southernstars.com/skymap.html) to magnitude 9 on desktop, and the [Messier](https://en.wikipedia.org/wiki/Messier_object) and [Caldwell](https://en.wikipedia.org/wiki/Caldwell_catalogue) deep sky objects.

SkyMap renders stars, constellations (stick figures, boundaries, labels), deep sky objects, planets, the Milky Way, coordinate grids and reference lines in both dark and light themes. It uses a stereographic projection with four different reference frames (Horizon, Equatorial, Ecliptic, Galactic). The view is zoomable and dragable; objects can be selected by clicking. You can animate the view with a time step from seconds to years.

Within a few hundred years of the present, SkyMap shows [planet positions](https://stjarnhimlen.se/comp/ppcomp.html) to sub-arcminute accuracy using Jean Meeus's [Astronomical Algorithms](https://shopatsky.com/products/astronomical-algorithms-2nd-edition) version of [VSOP87](https://cdsarc.cds.unistra.fr/ftp/VI/81/) and [ELP2000](https://cdsarc.cds.unistra.fr/ftp/VI/79/) for the Moon. Positions for the solar system's 24 major moons are computed with formulae from the [Explanatory Supplement to the Astronomical Almanac](https://aa.usno.navy.mil/publications/exp_supp) and orbits from JPL's [Planetary Satellite Mean Elements](https://ssd.jpl.nasa.gov/sats/elem/) page. Computation includes corrections for [Delta-T](https://eclipse.gsfc.nasa.gov/SEcat5/deltat.html), light time, precession, nutation, and atmospheric refraction.

At startup, SkyMap downloads [Minor Planet Center](https://minorplanetcenter.net/data) asteroids and comet files from [southernstars.com](https://southernstars.com) daily, and caches them in browser local storage for offline use. This lets SkyMap show bright asteroids and comets to a similar level of precision as the planets.

SkyMap downloads orbits for the ~150 brightest satellites from [Celestrak.org](https://celestrak.org/) daily as well. It computes satellite positions using [SGP4](https://celestrak.org/publications/AIAA/2008-6770/AIAA-2008-6770.pdf), and visual magnitudes with the McCants standard magnitude formula.

All code was generated by [Claude Code](https://claude.com/product/claude-code) - prompted, tweaked, heavily tested, and debugged by me (Tim DeBenedictis, timd@southernstars.com).

## Getting Started

Open [skymap.html](https://www.southernstars.com/skymap.html) in a browser. No build step or server required.

Getting your location from Wi-Fi will fail when opening the HTML file from local storage; to fix that, start a local server:

```
python3 -m http.server 8080
```

Then browse to http://localhost:8080/skymap.html

## Data Generation

The JavaScript data files (`stars.js`, `constellations.js`, `deepsky.js`, `cities.js`, `milkyway.js`) are pre-generated and checked in. The Python scripts in `data/` regenerate them from source catalogs:

```
cd data
python3 gen_stars.py brightest.csv 6.0    # -> stars.js
python3 gen_stars.py SKY2000.csv 8.0      # -> stars.js (extended catalog)
python3 gen_constellations.py             # -> constellations.js
python3 gen_deepsky.py                    # -> deepsky.js
python3 gen_cities.py                     # -> cities.js
python3 gen_milkyway.py                   # -> milkyway.js
python3 gen_vsop87.py                     # -> vsop87.js
```

Most scripts auto-download their source CSV files from [SSCore](https://github.com/timmyd7777/SSCore) if not already present. Move the generated `.js` files into the project root to update the app.
